# Fashion Trends Analysis

## About the Project

Fashion Trends Analysis is a Python-based data analytics project using fashion retail data from Reliance Trends. The project focuses on understanding fashion products, popular brands, product categories, pricing patterns, discounts, and customer preferences among men, women, and kids.

## Project Objectives

The main objective of this project is to identify the most common brands and product categories, analyze discount patterns, compare product preferences across genders, and study product distribution across Budget, Mid, Premium, and Luxury price segments.

## Dataset

The dataset contains information about brand names, product names, categories, gender, original prices, discounted prices, discount percentages, price segments, and discount tiers. These details help analyze product distribution, pricing strategies, and discount trends in fashion retail.

## Tools and Technologies

This project was developed using Python for data analysis, Pandas for data cleaning and manipulation, Matplotlib and Seaborn for data visualization, and Jupyter Notebook for writing and executing code.

## Project Workflow

In this project, I cleaned the dataset and checked for missing values to improve data quality. I explored the data to understand product prices, brands, and categories. I analyzed brand popularity and product distribution across categories, compared product types among men, women, and kids, and studied discount percentages and average discounts by gender. I also examined the relationship between product prices and discounts and analyzed product distribution across different price segments and discount tiers using charts and visualizations.

## Conclusion

This project helped me gain practical experience in data cleaning, exploratory data analysis, and data visualization using Python. It improved my understanding of how data analytics can be applied to real-world business problems, especially in analyzing fashion trends, pricing strategies, discount patterns, and customer preferences.
